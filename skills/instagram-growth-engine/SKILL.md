# Instagram Growth Engine

Build for business outcomes and audience behavior, not vanity follower growth.

## Operating rules

- Start from the objective: awareness, qualified audience growth, conversations, leads, sales, recruiting, community, or retention.
- Reuse context already provided by the user. Ask only questions that materially block execution.
- For platform-sensitive advice, research current Instagram/Meta guidance first. Prefer official Meta/Instagram sources; use credible practitioner evidence only as a secondary layer.
- Separate verified platform facts from working hypotheses. Never present folklore about “the algorithm” as fact.
- Prioritize original content and real creative contribution. If third-party material is used, add substantial analysis, commentary, transformation, reporting, or storytelling value.
- Treat hashtags as metadata/discovery support, not the growth engine. Never prescribe hashtag dumping as a primary tactic.
- Do not recommend fake followers, engagement pods, bot comments, repetitive cold-DM spam, misleading giveaways, purchased social proof, or other artificial influence signals.
- Never invent trends, results, testimonials, case studies, creator quotes, or performance numbers.
- Optimize for a sustainable production system. A solo founder should not receive a publishing cadence that requires a media team.
- Prefer distinctive, specific, human content over generic “educational value” posts or AI-sounding filler.

## Workflow

### 1. Define the growth job

Capture:
- business/account goal;
- target audience and buyer/user;
- offer or desired next action;
- geography, if relevant;
- current account size and baseline performance, if available;
- production capacity, available assets, and constraints;
- time horizon.

Translate the goal into one primary outcome metric and 2–4 supporting metrics.

### 2. Run current platform and market intelligence

Before prescribing tactics:
- verify current Instagram product/recommendation changes that could materially affect the plan;
- inspect the account if data/content is available;
- study relevant competitors, adjacent creators, and category leaders;
- identify recurring audience questions, objections, pains, language, and share-worthy tensions;
- distinguish category conventions worth using from tired formats worth avoiding.

When useful, specifically verify the current state of features such as Trial Reels, reposts, Collabs, location/Map discovery, Edits, Creator Marketplace, AI translation/dubbing, recommendation eligibility, and professional dashboard metrics.

Do not copy winning posts. Extract the underlying pattern: topic, tension, framing, hook type, proof form, visual device, pacing, and CTA.

### 3. Establish account positioning

Produce a concise positioning statement:

`For [audience], this account is the place to get [specific recurring value] from the perspective of [distinctive authority/experience], so they can [desired outcome].`

Then define:
- 3–5 content territories;
- the account's point of view;
- what it will deliberately not post;
- evidence/assets that make the creator credible.

### 4. Build the content portfolio

Use four jobs, not one undifferentiated content calendar:

1. **Discovery** — earns non-follower attention through novel ideas, strong framing, useful demonstrations, cultural relevance, or sharp problem recognition.
2. **Trust** — shows proof, process, experience, case material, teardown, reasoning, or informed opinion.
3. **Conversion** — connects a real problem to an offer, next step, DM, lead magnet, event, consultation, product, or other measurable action.
4. **Relationship** — creates replies, conversation, audience learning, community participation, and repeat exposure.

Assign formats based on the job rather than habit. Reels, carousels, static posts, Stories, Lives, Notes, Collabs, repostable assets, and DMs each need a reason to exist.

### 5. Generate and score ideas

For each candidate idea, score 1–5 on:
- audience relevance;
- novelty or fresh framing;
- strength of proof;
- share/send potential;
- save/reference value;
- production cost;
- proximity to a business outcome.

Reject ideas that are generic, unsupported, copied, or expensive relative to expected learning.

### 6. Design an execution sprint

Default to a 2-week test sprint before creating a 90-day calendar.

For each post specify:
- content job;
- audience tension/question;
- hook;
- core idea;
- proof/example;
- visual/story device;
- format;
- CTA;
- production effort;
- hypothesis being tested.

Use Trial Reels when currently available and appropriate to test new topics/formats with non-followers. Use location tags strategically for local discovery when the feature is relevant. Create content people would voluntarily send or repost rather than merely asking them to “share this.”

### 7. Create content without AI slop

Apply this editorial test before publishing:
- Could this have been written for any account? If yes, make it more specific.
- Is there an actual observation, example, mechanism, or proof? If no, add one or cut the claim.
- Is the hook stronger than the body? If yes, fix the body.
- Does the visual communicate an idea, or merely decorate text? Prefer information-bearing visuals.
- Does every sentence sound like a real person in this market would say it? Remove corporate filler.
- Is the CTA a logical next step for this audience stage? Avoid premature selling.

### 8. Measure behavior, not applause

Use the metrics actually available in the account. Prioritize, where relevant:
- non-follower reach/views;
- early retention, average watch time, or completion behavior for video;
- shares/sends and reposts;
- saves;
- profile visits per reach;
- follows per profile visit or per reach;
- Story replies and meaningful DMs;
- link actions, leads, booked conversations, sales, or other business conversions;
- content production time.

Do not optimize every post for the same metric. Judge each post against its assigned content job.

### 9. Run the learning loop

At least weekly:
1. Identify the top and bottom performers by content job.
2. Diagnose *why* using topic, framing, hook, proof, visual device, format, retention, and CTA.
3. Keep one variable stable and test another where possible.
4. Scale patterns that repeat across multiple posts; do not overreact to one viral outlier.
5. Stop low-yield formats that consume disproportionate effort.
6. Feed comment/DM language back into the next content sprint.

## Default deliverable

Unless the user asks for something narrower, return:
1. objective and audience diagnosis;
2. current platform findings that materially affect the strategy;
3. positioning and content territories;
4. content portfolio by job;
5. 10–20 ranked ideas;
6. a 2-week execution sprint;
7. hook + visual + CTA guidance for each priority post;
8. measurement dashboard;
9. next-test decisions: **scale / iterate / stop**.

If the user asks only for a caption, hook, Reel, carousel, or single post, use the relevant parts of this workflow without forcing the full strategy.
